🌱 Beginner guide — read this and you read any chart (zero → pro, step by step)

Let's work this out in a step-by-step way to be sure we have the right answer. You will know more than most interview candidates after these 6 steps:

  1. Two teams, one rope. Bulls pull price up, bears pull it down — both pull all the time. Rising price ≠ no sellers; it means buyers are stronger right now.
  2. One candle = one round. Body = net result (green = bulls won, size = margin). Wick = ground taken but not held (failed attack). Tiny body + long wicks = draw.
  3. Q1 — Who dominates? Stairs up (higher highs and higher lows) = bulls. Stairs down = bears. Otherwise = balanced struggle (a compressed spring, not a dead market).
  4. Q2 — How strong? 3 markers: big winner bodies · shallow pauses (<½ the advance) · 6+/10 candles aligned. Calm confident walk = strong. Violent jumps = volatility, not strength.
  5. Q3 — Tired or reversing? 3 markers: new depth (pullback deeper than priors) · failed advance (long wicks, no new ground) · momentum flip (opponent bodies bigger + consecutive). Need 3/3 to even describe a transfer — never to predict it.
  6. Memory + discipline. Old battlefields (≥3 touches, drawn as zones not knife-lines) show where fighting concentrates. A line may reveal; it may never decide for you. Describe the present; build a system (entry/exit/size/invalidation over 100s of trades) for the future.
